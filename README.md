# 🍔 Foodie - Food Ordering Application

A Java Full Stack Food Ordering Web Application where users can explore restaurants, view menus, add food items to their cart, and place orders.

## 🚀 Live Demo

https://foodie-food-ordering-app.onrender.com

## 🛠️ Technologies Used

- Java
- JSP
- Servlets
- HTML
- CSS
- JavaScript
- MySQL
- Apache Tomcat
- JDBC
- Git & GitHub
- Docker
- Render
- TiDB Cloud

## ✨ Features

- 🏪 Restaurant listing
- 🍽️ Restaurant menu
- 🛒 Add food items to cart
- 📦 Order management
- 👤 User management
- ⭐ Restaurant ratings
- 🗄️ MySQL-compatible database
- 🌐 Deployed online using Render

##  Project Architecture

The application follows a layered architecture:

- Controller
- DAO
- DAO Implementation
- Model
- Utility
- JSP Views

##  Deployment

The application is deployed using:

**GitHub → Docker → Render → TiDB Cloud**
